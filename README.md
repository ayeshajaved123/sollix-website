# Sollix — Corporate Website

Corporate website for an electromechanical services company, built with Flutter Web. Single-page marketing site with project galleries and a contact pipeline.

## Features
- Responsive single-page layout (mobile / tablet / desktop)
- Animated sections with scroll-reveal effects
- Project gallery, services, stats, CTA banner
- Contact form backed by Cloud Firestore
- Admin panel for managing projects, services, and submissions
- Media uploads via Cloudinary

## Tech Stack
Flutter · Dart · Firebase Authentication · Cloud Firestore · Cloudinary

## Run
```
flutter pub get
flutterfire configure
flutter run -d chrome
```
