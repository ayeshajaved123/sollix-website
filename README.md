# Sollix — Corporate Website

Corporate website for an electromechanical services company, built with Flutter Web. Single-page marketing site with service showcases, project galleries, company stats, and a contact pipeline backed by Firebase.

## Features
- Responsive single-page layout (mobile / tablet / desktop breakpoints)
- Animated hero, services, projects, stats, and CTA sections with scroll-reveal effects
- Project gallery and company values sections
- Contact form with Firestore-backed submissions
- Admin panel for managing projects, services, and contact submissions
- Image uploads via Cloudinary

## Tech Stack
- Flutter (Web) · Dart
- Firebase Authentication, Cloud Firestore
- Cloudinary (media uploads)
- google_fonts (Oswald + Inter)

## Getting Started

```bash
flutter pub get
```

### Firebase & Cloudinary setup

1. Run `flutterfire configure` and select your Firebase project (Web platform) to generate `lib/firebase_options.dart`.
2. Enable **Email/Password** sign-in and create a Firestore database.
3. Set your Cloudinary cloud name and upload preset in `lib/config/cloudinary_config.dart`.

### Run & build

```bash
flutter run -d chrome      # local development
flutter build web          # production build
```

## Project Structure

```
lib/
  main.dart               — app entry and routing
  firebase_options.dart   — generated by flutterfire configure
  config/                 — Cloudinary configuration
  theme/                  — colors, typography, responsive breakpoints
  models/                 — data classes (projects, services)
  services/               — Firebase Auth, Firestore, Cloudinary wrappers
  sections/               — page sections (navbar, hero, services, projects, footer…)
  screens/                — page assembly
  screens/admin/          — admin panel (login, dashboard, content managers)
assets/
  images/
web/                      — Flutter web shell and icons
```
